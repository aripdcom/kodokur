Book barcodes

Every EAN-13 that starts with 978 or 979 is an ISBN. Kodokur checks the check digit, splits the number into its parts using the ISBN International range table and reads the price from the 5-digit add-on behind it. The table is built into the app; no internet is needed.

What it reads

Linear barcodes (EAN, UPC, Code 128/39/93, ITF, Codabar, GS1 DataBar) and 2D codes (QR, Data Matrix, PDF417, Aztec). A barcode held sideways is read too.

Books

Hyphenated ISBN-13, ISBN-10, registration group and, if present, the price. Opens in Open Library, Google Books or a web search with one tap.

Magazines and newspapers

The ISSN from barcodes starting with 977, and the issue number from the 2-digit add-on. Opens in the ISSN Portal.

Products

EAN-13, EAN-8, UPC-A, UPC-E. Look them up in Open Food Facts if you like.

QR codes

Links, Wi-Fi (connect in one tap through the system dialog, the password stays hidden), e-mail, phone, SMS, locations and contact cards. Anything else can be copied as plain text.

From a photo, too

Reading a code from a picture needs no camera permission: the system photo picker hands over just that one image.

Counting a bookshelf

Batch scanning and CSV

In batch mode every code goes straight to the history without stopping, and the same book is never added twice. Share the history as a CSV file with ISBN-13 and ISBN-10 columns; spreadsheets open accented characters correctly.

Stays on the device

The app has no internet permission. The only permission is the camera; frames are examined on the phone and never saved or sent anywhere. Buttons such as book search hand the code to your browser. The scan history stays on your phone only and, because it can contain Wi-Fi passwords, is left out of backups. Privacy policy
